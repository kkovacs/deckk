Full-Width · Bare Panel

Two paragraphs share one column

A bare panel fills the body edge to edge. Swap it for a list or a table and nothing moves — typography is keyed to the slot, not the tag. The section counts its bodies: one means full width.

Two paragraphs stack in the same full-width body - no wrapper, no classes. Each one is gap-spaced above the next, margins zeroed, geometry still unstated in the markup.

Full-Width · Code

The navy slab is a slot panel, like any other

// one child => full width; a half shrinks the type by container query
function deckk(slide) {
  // zero custom JS - fragments and placeholders are native reveal
  const body = slide.querySelector('.body');
  return [...body.children].map(panel => panel.tagName);
}
Inline <code> is a quiet chip — panels are <pre class="code">
